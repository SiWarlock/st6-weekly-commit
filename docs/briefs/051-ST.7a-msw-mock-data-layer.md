# /tdd brief — ST.7a: MSW mock-data layer (standalone-only, contract-typed, state-spanning)

## Acceptance criteria
- [ ] **MSW lives in `src/standalone/` only** (e.g. `src/standalone/mocks/{handlers,fixtures,browser}.ts`), started in `src/standalone/main.tsx` **before the app mounts** (`await worker.start()`), gated to dev/demo (`import.meta.env.DEV`, optionally `VITE_USE_MOCKS`). It is **never imported by the remote** (`remote/WeeklyCommitApp.tsx`) — mirrors the demo-identity boundary (REQ-I-008).
- [ ] **The REQ-I-008 boundary proof is EXTENDED** to assert MSW (`msw`, `mockServiceWorker`, the handlers/fixtures) is **absent from the remote-exposed chunk** — both the fail-open import-graph assertion AND the fail-closed build-grep (LESSONS §6), with a positive control. (Safety-relevant invariant — this is the test-first pin.)
- [ ] **Fixtures are contract-typed** — each mock response is typed as its Appendix-B DTO (`const plan: WeeklyPlanDto = {…}`), so TS compile-enforces contract fidelity (the mock is a faithful double, not drifting from the wire contract).
- [ ] **Fixtures span the styling range** (the QA's whole point): a current plan in **each lifecycle state** (DRAFT / LOCKED / RECONCILING / RECONCILED — switchable, see Q1); commitments across **all** chess-field values (Priority P0/P1/P2 · WorkType STRATEGIC/MAINTENANCE/BLOCKER/UNPLANNED · Confidence HIGH/MEDIUM/LOW · AlignmentStatus ALIGNED/NEEDS_REVIEW/MISALIGNED), planned + unplanned + carried-forward, linked + **unlinked** SO, with reconciliation outcomes for RECONCILED; a command-center with rows of **varied counts** (misaligned/needsReview/blocked/carryForward/dispute) + review states incl. **overdue**; a heatmap with cells of **varied volume** (0/light/normal/heavy) + risk badges + a drilldown; a sync surface incl. a **FAILED** record; a flat comment thread.
- [ ] **Persona-aware:** the mock responds per the active `DEMO_PERSONA` (the `PersonaSwitcher` switches identity) — an IC persona sees their plan/commitments; a manager persona sees the command-center/heatmap + reports.
- [ ] The standalone app, run with mocks, renders **populated** surfaces on `/weekly-commit` · `/manager/command-center` · `/manager/heatmap` (the ST.7b QA precondition) — no error/empty states from missing data.
- [ ] `msw` added as a **devDependency** to `apps/wc-web/package.json` (+ the generated `public/mockServiceWorker.js`); root `yarn.lock` updated (frontend-owned — flag at Step 9). `yarn` typecheck + lint + prettier + full Vitest pass; the remote build stays mock-free.
