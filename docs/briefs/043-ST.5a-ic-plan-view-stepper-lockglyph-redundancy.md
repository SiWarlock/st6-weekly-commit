## Acceptance criteria
- [ ] `plan/PlanLifecycleBar.tsx` renders a **4-node stepper** for the four `PlanState` values **in lifecycle order** (DRAFT → LOCKED → RECONCILING → RECONCILED), derived from the current `plan.state`: nodes **before** the current state = `done`, the current = `active`, **after** = `pending`. Token-native (e.g. dot `h-4 w-4 rounded-full border-2`; done `bg-brand-600 border-brand-600`, active `border-brand-400 ring-2 ring-brand-soft`, pending `border-border-strong bg-surface`; connecting bar `h-0.5 flex-1` done `bg-brand-600` / pending `bg-border-strong`; label `text-meta` done|active `text-ink-primary font-medium` / pending `text-ink-muted`). The existing action buttons (LOCK / START_RECONCILIATION / ADD_UNPLANNED / CLOSE_RECONCILIATION, server-gated via `can()`) stay unchanged.
- [ ] The stepper is **derived display only** — no new server data, no `allowedActions` re-derivation; it reads `plan.state` (already present). It does **not** become a control (forward-only, non-clickable).
- [ ] `commitment/CommitmentList.tsx`: a **lock glyph** (`HiLockClosed`, `react-icons/hi`) is prepended to each commitment's title when `planState !== 'DRAFT'` (LOCKED / RECONCILING / RECONCILED); absent in DRAFT. (`§3` baseline-immutability is communicated visually; server stays authoritative.)
- [ ] `commitment/CommitmentList.tsx`: the **UNPLANNED redundancy is resolved** — an `UNPLANNED` commitment renders the kind-badge **OR** the WorkTypeTag, not both. **Default (confirm at 2.5):** keep the accent kind-badge (commitment-kind is structurally distinct), **suppress `WorkTypeTag` when `c.workType === 'UNPLANNED'`**. A non-UNPLANNED commitment still renders its `WorkTypeTag`.
- [ ] **Render-only — NO enum/Appendix-A change.** **No `.wc-*` CSS / no second stylesheet / no hardcoded hex / no arbitrary `[…]` hatches** (forbidden #3) — Tailwind/token utilities only (the ST.4 `tailwind.config` token set already covers what's needed; flag at 2.5 if a new token is wanted).
- [ ] Both `[data-theme]` values still render; `yarn` typecheck + lint + prettier + full Vitest suite pass.
