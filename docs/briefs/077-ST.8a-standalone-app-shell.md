- [ ] **REQ-I-008 preserved** — the app-shell + every new chrome component live under `src/standalone/`; `src/remote/boundary.test.ts` stays green (no new standalone module reachable from the remote import graph; no `BrowserRouter`/demo literal leaks into the remote closure). - [ ] **Token-native** — the new chrome contains no hex, no `.wc-*`, no CSS import, no arbitrary `-[…px]` hatches (the `surfaceSkin.test.ts` discipline). See Step-2.5 Q3 on adding the shell files to the scanned `TOUCHED_SURFACES`.

## RED test outline (Step 2)
Tests in `src/standalone/shell/AppShell.test.tsx` (render `<AppShell>` inside a `MemoryRouter` + the store/identity providers; assert on routing + gating + breadcrumb, NOT pixels):

1. **`nav_tab_navigates_to_route`** — manager persona: clicking the "Command Center" tab navigates to `/manager/command-center`; "Heatmap" → `/manager/heatmap`; "My Weekly Commit" → `/weekly-commit`.
   - Asserts: the router location updates to the expected path on click.
   - Why: §7 nav drives the existing `AppRoutes` (no new routes).
2. **`manager_tabs_persona_gated`** — IC persona renders a lone "My Weekly Commit" (no "My Team"/"Command Center"/"Heatmap"); manager persona renders the full segmented nav.
   - Asserts: the manager-only segments are absent for an IC, present for a manager (gate via the existing `useIsManager`).
   - Why: mirrors the route-gating in `AppRoutes` (manager routes are `isManager &&`).
3. **`active_tab_and_breadcrumb_reflect_route`** — mounted at `/manager/heatmap`: the Heatmap segment carries the active state and the breadcrumb reads "My Team › Heatmap"; at `/weekly-commit`: breadcrumb reads "My Weekly Commit › Week of Jun 1–7, 2026".
   - Asserts: active-state + breadcrumb derive from `useLocation()`, not local component state.
   - Why: prevents nav/route desync (the active tab must not drift from the URL).
4. **`persona_switch_preserves_reset_and_reroute`** — switching persona through the in-bar switcher invokes `setPersonaId` and the `resetApiState` path (LESSONS §16) and re-routes per `isManager` (manager → team surface; IC → `/weekly-commit`).
   - Asserts: the existing PersonaSwitcher contract is intact after the restyle (spy on the identity hook / assert the navigate target).
   - Why: regression guard — the restyle must not break the §16 identity-reset that the persona QA depends on.
5. **`boundary_req_i_008_still_green`** — `src/remote/boundary.test.ts` passes unchanged: the new `src/standalone/shell/*` modules are NOT in the remote import graph; the remote closure still has no `BrowserRouter`/`X-Demo-Employee-Id`/`demo-token`/`msw` literals; the positive controls still pass.
   - Asserts: the existing boundary suite is green (run it; if any new shell import path makes a standalone module remote-reachable, that's a RED to fix by keeping the import standalone-only).
   - Why: REQ-I-008 is the load-bearing demo-isolation guard.
6. **`shell_is_token_native`** *(if Q3 = add to scan)* — the new shell files contain no hex / no `.wc-*` / no CSS import / no arbitrary token hatch (the `surfaceSkin.test.ts` assertion set).
   - Asserts: the structural-guard regex set passes over the shell files.
   - Why: the directive is token-native everywhere, including demo chrome.
