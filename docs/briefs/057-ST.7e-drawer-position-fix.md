## Likely root cause (impl confirms)
`flowbiteTheme.ts:54` overrides the Drawer `root.base` with a minimal string:
```
base: 'fixed z-40 overflow-y-auto bg-surface-raised shadow-drawer'
```
This appears to **strip the width / full-height / right-anchor positioning** that flowbite-react's `position="right"` relies on (Flowbite's default `root.base` + `root.position.right` slots carry the `h-screen w-80 right-0 top-0 transform-none` positioning; the minimal override left the Drawer as a bare `fixed` element → top-left, content-sized). **Confirm at Step 2.5** whether it's the `root.base` override stripping positioning, a missing `position` slot in the custom theme, and/or the review Drawer (CommandCenter) missing the `position="right"` prop that HeatmapGrid has.
