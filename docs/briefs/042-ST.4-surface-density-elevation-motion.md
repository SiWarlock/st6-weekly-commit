# /tdd brief — ST.4: surface / density / elevation skin (max-widths · card skin · table density)

## Feature
Wire the Cadence **surface** tokens into the Tailwind theme and apply them to the product surfaces: (1) a token-native `maxWidth` scale (`reading-col` 1040 / `content-max` 1440) + a `hairline` elevation token, replacing the plain Tailwind-default widths on the three primary surfaces; (2) the Cadence `.wc-card` skin on the `CommitmentList` card — hairline-top inset + an **earned left-accent** (unplanned → accent); (3) `CommandCenter` table density — sticky header + hover rows + the 44px row rhythm. **Render-only, Tailwind/token-native (NO `.wc-*` CSS), no enum/Appendix-A change.** Second slice of the Phase-ST styling spine (after ST.3 atoms).

## Things to flag at Step 2.5
1. **Disputed → failure left-accent: DEFER (load-bearing scope call).** `WeeklyCommitmentDto` has no `dispute` signal until the backend B.6 Option-A edit (same blocker as 9.11a). **My default vote:** build **unplanned → accent only**; structure the accent helper (e.g. a small `cardAccent(c)` returning the border-l tone class or `''`) so `dispute → tone-failure-solid` is a one-line add when B.6 lands. **Do NOT** proxy "disputed" via `alignmentStatus === 'MISALIGNED'` — it's a distinct concept and already rendered as a `RiskBadge`. (I'll carry "disputed→failure accent" as a Carry-forward item that rides with 9.11a.)
2. **Row-height (44px) mechanism.** atoms render variable-height count cells, so a rigid `h-[44px]` on `<tr>` is fragile. **My default vote:** achieve the ~44px rhythm via consistent cell padding + line-height (keep current `py-3`-ish), and pin only the **deterministic** bits in tests (sticky thead + hover rows). If you'd rather add a `height`/`minHeight` token (`row: 'var(--row-height)'`) and assert it, flag it — fine, but the exact pixel fidelity is ST.7 `/design-review`.
3. **Token-wiring vs arbitrary values.** **My default vote:** add `maxWidth.{reading-col,content-max}` + `boxShadow.hairline` as `tailwind.config` tokens (keeps the codebase arbitrary-value-clean — only `Badge.tsx text-[11px]` remains). **Do NOT** use `max-w-[var(--reading-col)]` / `shadow-[inset_0_1px_0_var(--hairline-top)]` arbitrary hatches.
4. **ST.4 scope boundary.** The MVP_TASKS ST.4 line also lists "drawers/modals + scrim, focus ring, motion tokens." **My default vote:** drawers/modals/scrim → **ST.6** (no drawer/modal surface is mounted yet; that's `overlays.jsx` composition); the systematic `focus-visible`/`prefers-reduced-motion` a11y pass → **ST.7**. ST.4 ships the **unblocked surface/density/elevation subset** (widths + card skin + table density). Confirm this narrow scope — flag if you think a piece should pull forward.
