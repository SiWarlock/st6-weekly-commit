## RED test outline (Step 2)
1. **`demo_mode_attaches_demo_header_only`** — `VITE_AUTH_MODE=demo` → `prepareHeaders` sets `X-Demo-Employee-Id`, NOT `Authorization`. *Why:* §7 XOR.
2. **`auth0_mode_attaches_bearer_only`** — `VITE_AUTH_MODE=auth0` → awaits `getAccessToken()`, sets `Authorization: Bearer …`, NOT the demo header. *Why:* §7 XOR.
3. **`auth0_missing_accessor_surfaces_error`** — `auth0` mode with a missing/throwing `getAccessToken` yields a normalized error state, not an unhandled throw. *Why:* §7 host-integration resilience.
4. **`problem_json_parsed`** — a `409 application/problem+json` body parses into `{ safeMessage, code, fieldErrors }`. *Why:* B.21.
5. **`malformed_error_body_degrades`** — a non-problem/garbage error body yields a generic `safeMessage` without throwing. *Why:* B.21 robustness.
6. **`store_dispatch_sets_single_header_per_mode`** (integration) — dispatching a query through `baseApi` sets the correct **single** header per mode (mocked `fetch`). *Why:* the XOR holds end-to-end.
7. **`tag_types_cover_nine_domains`** — `tagTypes` equals the nine domain constants from `tags.ts`. *Why:* later slices invalidate against these.

## Things to flag at Step 2.5
1. **`getAccessToken` default resolver shape.** The contract is `(): Promise<string>`. **My default vote:** a module-level injectable accessor (settable by the standalone identity provider in this slice; host-overridable in remote mode at 9.3) — keep it a thin seam, no demo/persona logic here (that's standalone-only, wired in 9.3).
2. **Where `VITE_AUTH_MODE`/persona is read in `prepareHeaders`.** **My default vote:** read mode from `import.meta.env.VITE_AUTH_MODE`; the demo persona id comes from the injectable accessor/provider seam (not hardcoded), so the remote build carries no demo branch. Confirm version-correct RTK Query `fetchBaseQuery`/`prepareHeaders` typing via **Context7**.
3. **Error normalization placement.** **My default vote:** `problemDetails.ts` is a pure parser; RTK Query `transformErrorResponse` (per-endpoint, added with the real slices in 9.5+) calls it — this slice ships + unit-tests the parser, not per-endpoint wiring.
