## Feature
`POST /api/commitments/{id}/disputes` (E17, the active direct manager of the commitment's plan owner, parent plan `LOCKED`+) creates an `alignment_dispute` (status `OPEN`) with a required `managerNote` + `flagType`; rejects a second unresolved dispute on the same commitment with `409 SECOND_OPEN_DISPUTE`; re-derives the parent review's status to `REVIEWED_WITH_DISPUTES` if it was `REVIEWED` (same txn). Returns the new `AlignmentDisputeDto` (B.8).
