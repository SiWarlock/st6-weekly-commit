## Feature
`POST /api/manager/reviews/{reviewId}/mark-reviewed` (E16, the direct manager of the plan owner, plan `LOCKED`+) sets `reviewed_at` and derives the review status server-side via a new `ReviewStatusDeriver` (`REVIEWED_WITH_DISPUTES` iff the plan has ≥1 unresolved dispute, else `REVIEWED`), accepting an optional `summaryNote`; returns the updated `ManagerReviewDto`. Status is never client-supplied.
