## Acceptance criteria (`.github/workflows/deploy.yml`)
- [ ] **OIDC / no static keys:** top-level `permissions: { id-token: write, contents: read }`; every AWS step authenticates via `aws-actions/configure-aws-credentials` with `role-to-assume: <ci_deploy_role_arn>` (the env-scoped subject) — **no `aws-access-key-id`/`aws-secret-access-key`/static-secret inputs anywhere** (REQ-S-010/RISK-016).
- [ ] **Ordered chain (job/step `needs` enforce it — an out-of-order path is unreachable in the graph):**
  1. **gates** — ESLint 9, Prettier 3.3, Spotless, Vitest, **JaCoCo ≥80% per Gradle module** (api/worker/shared), SpotBugs, **local Cypress/Cucumber E2E against Docker Compose** (Testcontainers needs Docker-in-CI).
  2. **build-images** (`needs: gates`) — build + push `wc-api` + `wc-sync-worker` to ECR, **tagged the commit SHA** (§13).
  3. **deploy** (`needs: build-images`, `environment: production` → reviewer gate): (a) `terraform init` (S3+DynamoDB backend) + `plan` + `apply` — **installs the 12.2b cluster add-ons before any kubectl** ; (b) `aws eks update-kubeconfig` (via the CI EKS access entry); (c) **`envsubst` the 16-token allowlist** (LESSONS §14) into `infra/k8s/*` from `terraform output`; (d) `kubectl apply` the **migration Job** + **`kubectl wait --for=condition=complete job/<migration>`** BEFORE any Deployment/CronJob; (e) apply SAs/SPCs/Deployments/CronJob/Service/Ingress + roll; (f) build `wc-web` (`VITE_AUTH_MODE`, `VITE_API_BASE_URL=https://api.wc.${ROOT_DOMAIN}` — D.1) + `aws s3 sync` to the assets bucket + **CloudFront invalidation**; (g) **deployed smoke** (★Q-smoke).
- [ ] **Migration-before-deploy** is a hard graph edge (the `kubectl wait` gates the rolls); **`terraform apply`-before-`kubectl apply`** is a hard edge (addons + state must exist first).
- [ ] **Deployed smoke proves REQ-E-006:** `https://wc.${ROOT_DOMAIN}` serves the SPA (HTTP 200) and `https://api.wc.${ROOT_DOMAIN}/actuator/health/readiness` returns 200 over ACM TLS.
- [ ] **`actionlint .github/workflows/deploy.yml` rc=0**; the `${PLACEHOLDER}` envsubst tokens match the documented 16-token allowlist; the trigger is sane (e.g. `workflow_dispatch` + push to a release ref — ★Q-trigger).
