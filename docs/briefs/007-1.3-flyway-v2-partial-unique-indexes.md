## The 3 partial unique indexes (verbatim from §4)
1. `manager_relationship (direct_report_employee_id) WHERE active = true` — single active manager per report.
2. `alignment_dispute (commitment_id) WHERE status IN ('OPEN','IC_RESPONDED')` — at most one unresolved dispute per commitment.
3. `outlook_calendar_sync_record (owner_employee_id, week_start_date) WHERE event_kind = 'MANAGER_REVIEW_BLOCK'` — one review-block event per manager/week.
